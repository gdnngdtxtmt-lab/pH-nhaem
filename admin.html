🔑 Kết nối kho GitHub của website

Trang quản trị ghi nội dung trực tiếp vào kho GitHub đang liên kết với Vercel. Sau mỗi lần lưu, Vercel tự cập nhật trang chủ sau khoảng 1 phút.

Cách lấy mã truy cập (làm một lần)
  1. Đăng nhập GitHub, mở github.com/settings/personal-access-tokens/new.
  2. Đặt tên (VD: admin pH Nhà Em), chọn thời hạn (VD: 1 năm).
  3. Repository access → Only select repositories → chọn đúng kho của website.
  4. Permissions → Repository permissions → Contents: chọn Read and write.
  5. Bấm Generate token, sao chép mã bắt đầu bằng github_pat_ và dán vào ô trên.
🔒 Không gửi mã truy cập cho ai, không dán vào file trên GitHub. Nếu lộ mã, vào GitHub xóa mã đó và tạo mã mới.
