Đăng nhập quản trị

Dành cho giáo viên quản lý website pH Nhà Em: đăng thông báo, ảnh, bài tập, tài liệu lên trang chủ.

⚙️ Thiết lập lần đầu (chỉ làm một lần)

Đặt tên đăng nhập, mật khẩu và dán mã GitHub một lần. Mã được mã hóa bằng mật khẩu rồi lưu vào kho gdnngdtxtmt-lab/pH-nhaem. Từ lần sau chỉ cần tên đăng nhập + mật khẩu, trên bất kỳ máy nào.

Cách lấy mã truy cập
  1. Mở github.com/settings/personal-access-tokens/new.
  2. Đặt tên (VD: admin pH Nhà Em), chọn thời hạn (VD: 1 năm).
  3. Repository access → Only select repositories → chọn kho pH-nhaem.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Bấm Generate token, sao chép mã và dán vào ô trên.
